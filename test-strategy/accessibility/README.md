## 🎯 GOV.UK Standards

Key accessibility requirements for marine licensing:

- **WCAG 2.1 AA compliance** - Legal requirement for public sector
- **Screen reader compatibility** - Essential for users with visual impairments
- **Keyboard navigation** - Full functionality without mouse
- **Clear language and structure** - Accessible to users with cognitive differences
- **Responsive design** - Works across devices and zoom levels

## 🚀 Implementation Approach

Accessibility should be supported through:

- **User-centred design** with personas including accessibility needs
- **Semantic HTML** structure for screen reader compatibility
- **Progressive enhancement** ensuring core functionality works for all users
- **Clear error messages** and form validation feedback

## 🔍 Testing Approach

Planned accessibility testing includes:

- **Automated testing** with axe-core integration
- **Manual testing** with screen readers and keyboard navigation
- **User testing** with people who have accessibility needs
- **Design review** against GOV.UK Design System patterns
