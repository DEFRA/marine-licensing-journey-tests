# Attribution - Testing Methodology Foundations

This document acknowledges the foundational work and thought leaders whose methodologies our marine licensing testing approach builds upon.

## 🙏 Core Contributors

### **Michael Bolton**

**Contributions to our approach:**

- **Scenario Testing Framework** - THEME → SETUP → ACTIVITIES → ORACLES → VARIATIONS structure used throughout our investigative charters
- **"Breaking the Test Case Addiction"** series - Philosophy underlying our move from scripted to scenario-based testing
- **Realistic user investigation** principles that guide our charter development
- **Context-Driven Testing** school co-founder
- **Rapid Software Testing** methodology co-founder (with James Bach)

**Where we apply this work:**

- All investigative test charters follow Bolton's scenario structure
- User-centred testing philosophy throughout our strategy
- Emphasis on realistic user behaviour over artificial test cases

**References:**

- [Michael Bolton's blog](https://www.developsense.com/)
- **Rapid Software Testing** methodology (co-founded with James Bach)
- "Breaking the Test Case Addiction" blog series

## 🎯 How We Build Upon These Foundations

### **Respectful Integration**

Our **Investigative Testing** approach:

1. **Preserves core principles** from each methodology
2. **Adapts to marine licensing domain** requirements
3. **Integrates complementary approaches** into a unified framework
4. **Maintains attribution** to original thought leaders
5. **Extends for government service** needs and constraints

### **Specific Adaptations**

#### **Bolton's Scenario Testing**

- **Original:** THEME → SETUP → ACTIVITIES → ORACLES → VARIATIONS
- **Our adaptation:** Enhanced with marine licensing personas (Zofia, Amy, Fatima, Simon) and domain-specific pressures

#### **Bach's HTSM**

- **Original:** Structure/Behaviour/Value quality criteria
- **Our adaptation:** Applied to marine licensing workflows with domain-specific heuristics (MARINE, EXEMPTION models)

#### **Jon Bach's SBTM**

- **Original:** Time-boxed sessions with charters
- **Our adaptation:** 90-minute sessions optimised for marine licensing investigation complexity

#### **Context-Driven Principles**

- **Original:** Testing strategy driven by context
- **Our adaptation:** Specific marine licensing regulatory and user context integration
