# ML-1 Investigative Charter: Efficiency Patterns

## Session Charter

**SESSION CHARTER:** Investigate project name workflow through veteran user lens to discover efficiency barriers and workflow friction for experienced marine licensing applicants

**Duration:** 90 minutes  
**Priority:** Medium

## Scenario Context

### **THEME**

Discover workflow inefficiencies and missed optimisation opportunities for users familiar with marine licensing and government digital services

### **SETUP**

- **Primary Persona:** Amy (Veteran Applicant)
- **User Context:** Third marine licensing application this year, familiar with regulatory requirements
- **Technology Context:** Desktop computer with multiple tabs, keyboard shortcuts preference, browser bookmarks
- **Environmental Context:** Office environment with regular workflow interruptions
- **Efficiency Context:** Time-pressed due to multiple client applications, expects streamlined process

### **REALISTIC PRESSURES**

- **Time efficiency expectations** - Process should be faster than first-time users
- **Pattern recognition** - Expects familiar workflows from other government services
- **Data reuse assumptions** - Should be able to reuse information from previous applications
- **Keyboard navigation preference** - Minimal mouse usage, tab-through efficiency
- **Multiple application management** - Handling several projects simultaneously

## Scenario Activities

### **Guided Realistic Actions**

#### **Efficient Entry Approach (Veteran User Behaviour)**

- Navigate quickly to project name field using keyboard shortcuts
- Attempt to tab through form efficiently without mouse interaction
- Look for auto-complete or suggestion features based on previous applications
- Try to reuse project naming patterns from previous successful applications
- Expect streamlined validation that doesn't slow down experienced users

#### **Pattern Recognition and Shortcuts**

- Apply naming conventions learned from previous marine licensing applications
- Use keyboard shortcuts expected from other government services (Ctrl+S, Enter, Tab)
- Look for "Save as draft" functionality to handle multiple applications
- Attempt to open multiple applications in different tabs for comparison
- Try to copy information from completed applications for consistency

#### **Efficiency Optimisation**

- Minimise mouse usage throughout the workflow
- Expect smart defaults based on user history or common patterns
- Look for bulk operations or multi-application features
- Test rapid completion without careful reading of guidance (realistic veteran behaviour)
- Attempt to skip guidance that seems familiar from previous applications

#### **Workflow Integration**

- Navigate between project name and other application sections efficiently
- Test browser back/forward button usage without losing work
- Attempt to bookmark specific application states for later return
- Use browser autofill and form memory features
- Handle multiple client applications without confusion

### **Realistic Variations and Turbulence**

#### **Client Service Pressure**

- Handle phone call from client asking about application status mid-task
- Switch between different client applications requiring different naming approaches
- Manage deadline pressure with multiple applications due same day
- Balance speed requirements with accuracy for professional reputation
- Coordinate project names across planning applications and marine licensing

#### **Technology Efficiency Expectations**

- Expect page loading to be fast enough for rapid workflow
- Assume form validation won't interrupt efficient keyboard navigation
- Rely on browser features like autofill and form memory
- Use multiple browser tabs for application comparison and reference
- Expect system to remember preferences and settings between sessions

#### **Professional Workflow Complications**

- Different client preferences for project naming conventions
- Need to maintain consistency across multiple related applications
- Balance between speed and double-checking for client accuracy
- Handle interruptions from colleagues familiar with previous applications
- Document decisions for client billing and project management

## Scenario Oracles

### **Efficiency Quality Indicators**

#### **Positive Signals:**

- **Keyboard navigation fluency** - Tab order logical, shortcuts work intuitively
- **Recognition over recall** - Previous patterns easy to apply, smart suggestions available
- **Progressive enhancement** - Advanced features available for experienced users
- **Workflow continuity** - Smooth transitions between related tasks and sections
- **Time optimisation** - Clear paths for users who understand the domain and process

#### **Warning Signs:**

- **Efficiency barriers** - Required steps that slow down experienced users unnecessarily
- **Pattern disruption** - Workflows that conflict with established government service conventions
- **Cognitive switching costs** - Interface requires different mental models from similar processes
- **Forced guidance consumption** - Cannot skip familiar information without accessibility impact
- **Navigation inefficiency** - Mouse required for actions that should support keyboard shortcuts

### **Professional User Experience Indicators**

#### **Workflow Support:**

- **Multi-application management** - Easy to handle several projects simultaneously
- **Consistency tools** - Help maintaining standard approaches across applications
- **Reference accessibility** - Easy access to previous application examples and patterns
- **Status tracking** - Clear visibility of progress across multiple applications
- **Professional presentation** - Interface supports confident client interaction

#### **Efficiency Features:**

- **Smart defaults** - Reasonable assumptions based on user behaviour patterns
- **Bulk operations** - Support for common multi-application scenarios
- **Workflow shortcuts** - Advanced features that don't compromise accessibility
- **Context switching** - Smooth movement between different client work
- **Progress preservation** - Work saved appropriately during task switching

## Evidence Collection Framework

### **Discovery Documentation**

#### **Efficiency Evidence:**

- **Navigation speed** - How quickly can experienced users complete familiar tasks?
- **Workflow friction** - What slows down users who understand the domain?
- **Pattern recognition** - How well does interface support learned behaviours?
- **Shortcut effectiveness** - Which efficiency features work and which are missing?

#### **Professional Workflow Evidence:**

- **Multi-application support** - How well does system support managing multiple projects?
- **Consistency maintenance** - Can users maintain professional standards across applications?
- **Client interaction** - Does interface support confident client communication?
- **Time management** - How does system behaviour affect billable time and deadline management?

#### **Technology Integration Evidence:**

- **Browser feature compatibility** - How well do expected browser features work?
- **Keyboard navigation completeness** - Can entire workflow be completed without mouse?
- **Performance under load** - How does system respond to rapid experienced user interaction?
- **Cross-tab functionality** - Does multi-tab usage work as expected?

### **Problem Classification**

#### **Critical Issues (Immediate Attention)**

- Keyboard navigation breaks or prevents task completion
- Data loss during multi-application workflows or task switching
- Performance issues that significantly impact professional efficiency
- Interface conflicts that force inefficient workflows for experienced users

#### **Significant Issues (High Priority)**

- Workflow friction that unnecessarily slows experienced users
- Missing efficiency features that professionals expect
- Pattern inconsistencies that disrupt learned behaviours
- Professional presentation issues that affect client confidence

#### **Improvement Opportunities (Medium Priority)**

- Additional shortcuts that would improve efficiency
- Smart features that could reduce repetitive work
- Workflow optimisations for multi-application scenarios
- Professional tools that would enhance user confidence
