# ML-9 Usability Charter: User Experience & Workflow

## Charter Definition

**EXPLORE:** Task list user experience, workflow efficiency, and process understanding  
**WITH:** Different user personas, real-world scenarios, comparative analysis  
**TO DISCOVER:** How well the task list serves marine licensing applicants and staff

**Duration:** 90 minutes  
**Priority:** Medium  
**User Personas:** All personas with focus on first-time vs experienced users

## Background Context

**User Story:** ML-9 - View the Task List  
**UX Focus:** Task list as the "home page" of the notification process

**Key User Experience Goals:**

- Help users understand what they need to provide
- Support returning to work after breaks
- Create confidence in the process
- Enable efficient task completion

## Investigation Areas

### **First Impressions & Mental Models**

- What do users think they need to do when they first see the task list?
- Does the page match expectations from other government services?
- How overwhelming or manageable does the process appear?
- What questions do users have when they first arrive?

### **Process Understanding**

- Can users understand the overall marine licensing process from the task list?
- Do they know what information they'll need to gather?
- Is the sequence of tasks logical and intuitive?
- How well does the interface prepare users for upcoming tasks?

### **Workflow Support**

- How well does the task list support interrupted work sessions?
- Can users easily resume where they left off?
- Does the interface help users prepare for upcoming tasks?
- How does it support users who want to complete tasks out of order?

### **Confidence & Motivation**

- Does the task list make the process feel manageable?
- How does seeing completed tasks affect user confidence?
- Are users motivated to continue through the process?
- Does the interface reduce anxiety about marine licensing complexity?

## Persona-Specific Usability Scenarios

### **Zofia (Novice Applicant) - Learning Journey**

**Scenario:** First marine licensing application, unfamiliar with requirements

**Usability Questions:**

- Does the task list help her understand what marine licensing involves?
- Can she estimate how long the process will take?
- Are task names meaningful to someone new to marine licensing?
- Does the interface provide enough confidence to continue?

**Investigation Tasks:**

1. Load task list as a first-time user
2. Try to understand what each task involves
3. Assess overall complexity and time commitment
4. Look for guidance or help information
5. Evaluate emotional response to the interface

### **Amy (Veteran Applicant) - Efficiency Focus**

**Scenario:** Has completed marine licensing applications before, wants efficiency

**Usability Questions:**

- Can she quickly see what's different from previous applications?
- Does the task list support her efficient working style?
- Are there any unnecessary steps or friction points?
- How well does it integrate with her existing workflow?

**Investigation Tasks:**

1. Review task list with experienced user perspective
2. Compare to expectations from previous systems
3. Identify any inefficiencies or redundancies
4. Test rapid navigation between tasks
5. Evaluate time-to-completion factors

### **Fatima (Case Officer) - Review & Assessment**

**Scenario:** Reviewing application progress and supporting applicants

**Usability Questions:**

- Can she quickly understand application completeness?
- How well does the task list support her advisory role?
- What information would help her assist applicants?
- Does the interface support case management workflows?

**Investigation Tasks:**

1. Review task list from case management perspective
2. Assess information available for applicant support
3. Evaluate application progress visibility
4. Test use for phone-based applicant assistance
5. Consider integration with back-office systems

## Comparative Analysis

### **Government Service Benchmarks**

Compare task list patterns with:

- **GOV.UK services** - Tax returns, passport applications
- **Planning applications** - Local authority systems
- **Licensing services** - Alcohol licenses, waste permits

**Analysis Questions:**

- How does the task list compare to similar government services?
- What patterns do users expect from other services?
- Are there any innovative approaches worth considering?
- How does complexity compare to similar processes?

### **Commercial Service Patterns**

Consider patterns from:

- **Banking applications** - Account opening, loan applications
- **Insurance** - Policy applications, claims processes
- **E-commerce** - Multi-step checkout processes

**Learning Points:**

- What makes complex processes feel manageable?
- How do successful services communicate progress?
- What techniques reduce abandonment in multi-step processes?

## Workflow & Process Design

### **Information Architecture**

- Is the task organisation logical for marine licensing work?
- Do task names clearly communicate what's required?
- How well does the grouping support user mental models?
- Are there opportunities for better categorisation?

### **Progress Communication**

- How effectively does the interface communicate progress?
- What additional progress indicators might be helpful?
- How does completion status affect user motivation?
- Are there opportunities for better progress visualisation?

### **Task Sequencing**

- Does the current order make sense for most users?
- How important is linear vs non-linear task completion?
- What dependencies exist between tasks?
- How might task order affect user experience?

## Edge Case Usability

### **Incomplete Session Recovery**

- What happens if users return after days or weeks?
- How well does the interface help them remember context?
- Are there any confusing states after long breaks?
- How does the system help users restart efficiently?

### **Error States & Recovery**

- How does task list behaviour change when tasks have errors?
- Can users understand what went wrong from the task list?
- How well does error recovery integrate with task list navigation?
- Are error states motivating or discouraging?

### **Complex Application Scenarios**

- How does the task list handle marine licensing complexity?
- What happens with unusual project types or locations?
- How well does it scale for complex multi-site applications?
- Are there scenarios where the task list becomes overwhelming?

## Emotional & Cognitive Load

### **Cognitive Burden Assessment**

- How much mental effort does the task list require?
- Is the information density appropriate?
- Are there any cognitively demanding aspects?
- How well does it support users with different cognitive abilities?

### **Emotional Response**

- Does the task list create confidence or anxiety?
- How does it affect user motivation to complete the process?
- Are there any emotionally negative aspects?
- How does it compare to user expectations?

### **Decision Making Support**

- Does the task list help users make good decisions?
- Are there any confusing choices or unclear options?
- How well does it support users who need to gather information?
- Does it help users understand consequences of their choices?

## Success Indicators

### **Excellent Usability**

- Users quickly understand what they need to do
- Task list feels manageable and approachable
- Process appears logical and well-organised
- Users feel confident about completing the application
- Interface supports efficient work for all user types

### **Areas for Improvement**

- Confusion about task requirements or process
- Overwhelming complexity or cognitive load
- Poor progress communication or motivation
- Inefficient workflows for any user type
- Emotional barriers to process completion

## Documentation Focus

Record:

- **First impression observations** - User reactions and understanding
- **Workflow efficiency notes** - Time-to-task and navigation patterns
- **Emotional response indicators** - Confidence, anxiety, motivation
- **Comparative analysis insights** - How it compares to other services
- **Persona-specific findings** - Different user type experiences

## Follow-up Actions

- Document UX improvements for task list design
- Identify content changes to improve clarity
- Note automation scenarios for usability testing
- Provide recommendations for progress communication
- Share insights with design and product teams
