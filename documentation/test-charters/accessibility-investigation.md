# Accessibility Check for Beta

## Quick Test (30 minutes)

If your beta includes users with disabilities, check:

### Keyboard Only

- Unplug your mouse
- Can you complete an application?
- Note where you get stuck

### Screen Reader

- Download NVDA (free)
- Close your eyes
- Can you navigate the form?

### Key Questions

1. **Should disabled users be in beta?** If they can't use it, exclude them
2. **What's the minimum fix?** Focus on blockers, not perfection
3. **Support implications?** Will you get calls from stuck users?

## Beta Decision

- **Include disabled users**: Only if basic navigation works
- **Exclude for now**: If major barriers exist
- **Document blockers**: Fix before full release

---

_Beta doesn't need perfect accessibility. It needs to not waste disabled users' time._
