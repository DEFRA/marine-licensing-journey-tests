# ML-271: Dynamics User View Read-Only Version of Notification

## User Story

**AS** an internal user  
**I WANT** to be able to view the details of the notification  
**SO THAT** I can fully understand the content of the exempt activity

## Background

This page is effectively a stripped-down version of the "Check your answers" page with all of the CTAs and navigation options removed. The intention is for the user to view this page from Dynamics, then close it when they are finished.

This page is being served from the app, not D365.

## Acceptance Criteria

### AC1 - Display page

**GIVEN** I am viewing the URL for the "Notification summary" page  
**WHEN** the page is loaded  
**THEN** the page will contain the details of the notification that is specified in the URL:

- The page caption will contain the unique reference number
- The page title will contain the project name
- The content of each summary card on the page will be as defined in the following ACs

### AC2 - "Application details" summary card

**GIVEN** I am viewing the URL for the "Notification summary" page  
**WHEN** I view the "Application details" summary card  
**THEN** I see the following information:

- **Application type** - "Exempt activity notification"
- **Reference number** - repeated from the title
- **Date submitted**

**NOTE** - This card is slightly different from the original.

### AC3 - "Project summary" card

**GIVEN** I am viewing the URL for the "Notification summary" page  
**WHEN** I view the "Project summary" card  
**THEN** I see the following information populated from the IAT:

- **Type of activity**
- **The purpose of the activity**
- **The applicant's answers from "Check if you need a marine licence"**
- **Why this activity is exempt**

**NOTE** - The copy on this card is slightly different from the original.

### AC4 - "Providing the site location" summary card

**GIVEN** I am viewing the URL for the "Notification summary" page  
**WHEN** I view the "Providing the site location" summary card  
**THEN** I see the following information:

- **Method of providing site location** - Manual or uploaded
- **More than one site** - Yes or No

### AC5 - "Site details" summary card

**GIVEN** I am viewing the URL for the "Notification summary" page  
**AND** I have provided the details of my site using file upload  
**WHEN** I view the "Site details" summary card  
**THEN** I see the same "Site details" summary card that appears on the "Review site details" page and "Check your answers" page

### AC6 - "Public register" summary card

**GIVEN** I am viewing the URL for the "Notification summary" page  
**WHEN** I view the "Public register" summary card  
**THEN** I see the same "Public register" summary card that appears on the "Check your answers" page

## Standard Behaviour

**Read-only display** - the page provides view-only access to notification details with no interactive elements, navigation buttons, or editing capabilities.

**External access** - the page is designed to be accessed from Dynamics 365 and should display correctly when viewed from external systems.

**Content preservation** - all summary card information should match exactly with the content from the original "Check your answers" page, ensuring data consistency across views.

**Page closure** - users are expected to close the page manually when finished reviewing the notification details, as no navigation or return options are provided.
